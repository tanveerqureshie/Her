# Aastha Pasrija — Software Engineer Portfolio

An award-winning, minimalist software engineering portfolio built for **Aastha Pasrija** with modern aesthetics inspired by Apple, Linear, and Awwwards-winning developer sites.

## 🌟 Highlights & Features

1. **Brand & Navbar**:
   - Monogram logo (`AP`) and custom typography for `AASTHA PASRIJA`.
   - Live availability badge (`Open to Software Engineering & AI/ML Opportunities`).
   - Smooth scroll spy navigation: About, Toolkit, Projects, Academics, Contact.
   - Dark & Light mode toggle with persistent `localStorage` memory and system preference detection.
   - Mobile-responsive sliding navigation drawer.

2. **Hero Section with Autoplay Video**:
   - High-impact minimalist typography with gradient text highlights.
   - Personalized tagline tailored for AI/ML & Full-Stack software engineering.
   - Direct CTA buttons: **"View My Projects"** and **"GitHub Profile"**.
   - Embedded showcase reel using [`Herro section.mp4`](./Herro%20section.mp4) with seamless loop autoplay (`autoplay`, `muted`, `loop`, `playsinline`), live status pill, sound toggle (Mute / Unmute), and fullscreen button.

   - Filterable skills grid (`All`, `LANG`, `AI/ML`, `DEV`).
   - Authentic SVG vector icons for each skill:
     - **Python** `[LANG]`

     - **Computer Vision** `[AI/ML]`

   - Interactive Left / Right navigation arrows, slide counter (`01 / 02`), and progress dots.

## 🚀 How to Run & Preview

Open `index.html` directly in any browser, or run a local HTTP server:

```bash
# Using Python
python3 -m http.server 3000

# Or using Node
npm start
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
